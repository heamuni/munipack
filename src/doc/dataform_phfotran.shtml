Photometric Systems Transformation Table

Definition of a FITS table providing the transformation between photometric systems.

The table is created by munipack phfotran action and used by phcal action.

This specification has been developed for internal use in Munipack and backward compatibility is not guarantied.

File Structure

The primary HDU has no data; its header identifies the photometry systems, the model of the transformation (TRAMODEL) and records the frames the transformation has been derived from (in comments). There are two models: FLUX, the linear mixing of photon rates (the matrices below), and MAG, the colour terms of the magnitudes (the table FOTRAN_MAG). A table without TRAMODEL (written by the versions before the magnitude model) is a FLUX table.

The magnitude model

The table FOTRAN_MAG has one row per filter (in the order of the photometry system):

mstd − minst = ZP + K1 (c − CREF) + K2 (c − CREF)², c = mstd(COLOR_A) − mstd(COLOR_B),

minst = −2.5 log10(count rate [counts/s/m²]), mstd the magnitude of the standard system.

Columns of FOTRAN_MAG
ColumnDescriptionUnits
FILTERthe filter
COLOR_A, COLOR_Bthe filters of the colour c
CREFthe reference colourmag
ZP, ZPERRthe zero point and its error (phcal fits its own)mag
K1, K1ERRthe linear colour term and its errormag/mag
K2, K2ERRthe quadratic colour term (0 for the order 1)mag/mag²
SYSERRthe systematic error of the fitmag
RMSthe scatter of the stars around the fitmag
NSTARSthe stars of the fit

phcal checks the systems and the filters, takes K1, K2, CREF and the colours, and fits the zero points itself.

The flux model

The matrices are tables with one column per filter (named by the filter, in the order of the photometry system) and one row per filter in the same order: the element Tij is in the row i and the column j. The rates are per second and square metre:

ci = Σj Tij pj

where c are the count rates in the instrumental filters and p the photon rates in the standard filters (the forward matrix). phcal checks the systems and the filters (the names of the columns) against the calibration, uses the forward matrix for the calibration and its inverse for the conversion of counts to photons; the backward matrix is not used.

The data table has the columns RAJ2000, DEJ2000, PH_f, ePH_f [ph/s/m²] (the catalogue photons), CTS_f, eCTS_f [counts/s/m²] (the frames) for every filter f.

The table can be created by hand, but the structure must be respected and all identifiers included.
